# FOCUS FLOW — Персональный планировщик задач, времени и продуктивности

Полноценное, визуально выразительное веб-приложение для управления задачами, концентрации и отслеживания ежедневного прогресса.

Разработано в строгом соответствии с требованиями фронтенд-бенчмарка: **чистый HTML5, CSS3 и Vanilla JavaScript (ES-модули)** без использования фреймворков (React/Vue/Angular), сторонних runtime-серверов или обязательного этапа сборки.

---

## 🌟 Ключевые возможности

### 1. Dashboard (Главный экран)
- Приветствие с автоопределением времени суток (утро, день, вечер, ночь) и текущей датой.
- Круговой индикатор суточного прогресса выполнения запланированных задач.
- Автоматический подсчёт непрерывной серии продуктивных дней (Streak).
- Счётчик чистого времени глубокого фокуса за сегодня и суммарно.
- Интерактивная векторная гистограмма (SVG) активности за последние 7 дней с всплывающими подсказками.
- Ближайшие запланированные задачи и панель быстрых действий («Новая задача», «Запустить фокус», «Календарь»).

### 2. Задачи (Tasks)
- **Полный жизненный цикл (CRUD)**: создание, детальное редактирование, завершение и удаление.
- **Подзадачи (Checklists)**: неограниченное число подзадач с прогресс-баром и синхронизацией завершения.
- **Приоритеты**: `Срочный` (Urgent), `Высокий` (High), `Средний` (Medium), `Низкий` (Low) с индивидуальным цветовым кодированием.
- **Категории**: `Работа`, `Учёба`, `Личное`, `Здоровье`, `Проекты` с бейджами.
- **Дедлайн и хронометраж**: дата, время и примерная продолжительность в минутах.
- **Фильтрация и поиск**: фильтрация по статусу (*Все*, *Сегодня*, *Предстоящие*, *Выполненные*), категориям, приоритетам, а также мгновенный поиск по названию и описанию.
- **Сортировка**: по дедлайну, приоритету, названию или ручной порядок.
- **Drag & Drop**: интуитивное изменение очерёдности задач перетаскиванием (HTML5 Drag and Drop API).

### 3. Pomodoro-таймер (Фокус)
- 3 режима: **Фокус** (25 мин), **Короткий перерыв** (5 мин), **Длинный перерыв** (15 мин) с циклом из 4 раундов.
- **Анти-дрейф движок**: расчёт времени по меткам `Date.now()`, предотвращающий замедление таймера при переходе в фоновые вкладки браузера.
- Интерактивное круговое SVG-кольцо прогресса с плавной анимацией.
- Синхронизация статуса и обратного отсчёта в заголовке вкладки (`(24:59) Фокус | FOCUS FLOW`).
- Привязка таймера к конкретной задаче из списка.
- **Встроенный аудио-синтезатор (Web Audio API)**: гармонические сигналы начала и окончания сессий без внешних mp3-файлов.

### 4. Интерактивный календарь (Calendar)
- Сетка месяца (Пн–Вс) с переключением месяцев и быстрым переходом к сегодняшнему дню.
- Точечные индикаторы и счётчики задач на каждой дате.
- Инспектор выбранного дня: список задач на дату, отметка выполнения и кнопка быстрого добавления задачи с предустановленной датой.

### 5. Аналитика (Analytics)
- KPI-карточки: Всего задач, Выполнено, Процент завершения %, Часы фокуса, Текущая и рекордная серии дней.
- Интерактивный график недельной активности (SVG Bar Chart).
- Круговая диаграмма распределения задач по категориям (SVG Donut Chart) с цветовой легендой.
- Журнал недавних сессий концентрации.

### 6. Настройки и безопасность данных (Settings)
- **Две темы оформления**: *Obsidian Dark* (тёмная по умолчанию) и *Paper Light* (чистая светлая).
- Настройка длительности фокуса и перерывов.
- Регулировка громкости и тестовое воспроизведение звукового сигнала.
- **Резервное копирование**: экспорт всех задач, сессий и настроек в файл `focus-flow-backup.json`.
- **Импорт данных**: восстановление из JSON с валидацией схемы и защитой от XSS.
- Сброс данных и загрузка реалистичного демо-набора в один клик.

### 7. Горячие клавиши (Keyboard Shortcuts)
- `N` — Создать новую задачу
- `Пробел` — Старт / Пауза таймера
- `1` ... `5` — Быстрое переключение экранов
- `Esc` — Закрыть любое модальное окно
- `?` — Справка по горячим клавишам

## 🚀 Запуск и публикация на GitHub Pages

Приложение спроектировано как полностью автономный статический сайт с относительными путями (`./css/style.css`, `./js/app.js`):

1. Создайте репозиторий на GitHub и загрузите файлы проекта (`index.html`, папки `css/`, `js/`).
2. В репозитории откройте **Settings** → **Pages**.
3. В блоке **Build and deployment** выберите:
   - Source: `Deploy from a branch`
   - Branch: `main` (или `master`), папка `/ (root)`
4. Нажмите **Save**. Через 1–2 минуты сайт станет доступен по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

*Никаких настроек сборщика, GitHub Actions или Node.js не требуется.*

## 📁 Архитектура проекта

```text
├── index.html            # Семантическая разметка экранов, модальных окон и SVG-иконок
├── css/
│   └── style.css         # Модульная дизайн-система: CSS Variables, тёмная/светлая темы, компоненты
├── js/
│   ├── app.js            # Главная точка входа, связывание событий и модальных окон
│   ├── ui.js             # Отрисовка представлений, тосты, тема, клавиатурные сокращения
│   ├── tasks.js          # Логика задач, подзадач, фильтрация, сортировка, DnD, серии
│   ├── timer.js          # Точный таймер фокуса на Date.now() и журнал сессий
│   ├── calendar.js       # Генерация сетки календаря и инспектор дат
│   ├── analytics.js      # Расчёт метрик, генерация SVG-диаграмм
│   ├── audio.js          # Синтезатор звуковых сигналов на Web Audio API
│   └── storage.js        # Менеджер LocalStorage, защита от XSS, демо-данные
└── test/
    └── planner.test.js   # Автоматические тесты чистой логики (node:test)
```

## 🧪 Тестирование
Для запуска модульных тестов:
```bash
node --test test/planner.test.js
```
Все 7 тестов проверяют экранирование XSS, валидацию схемы JSON, CRUD задач, каскад подзадач, непрерывные серии, таймер и аналитический движок.
